Kelley Autoplex Booking Widget — embed code

Drop this anywhere on a page. The widget mounts into the div with id
"kelley-booking-widget" and handles theme, calendar, three-step booking,
attribution capture, and abandon telemetry on its own.

  <div id="kelley-booking-widget"></div>
  <script src="https://api.kelleyautoplex.com/widgets/kelley-booking-widget.js" defer></script>
  <script>
    document.addEventListener('DOMContentLoaded', function () {
      window.KelleyBookingWidget.init({
        containerId: 'kelley-booking-widget',
        apiBaseUrl: 'https://api.kelleyautoplex.com'
      });
    });
  </script>

Configuration options
---------------------
containerId  (string)  ID of the empty div the widget mounts into.
                       Default: "kelley-booking-widget".
apiBaseUrl   (string)  Origin where /api/booking/* lives.
                       Default: "" (same origin as the page).

Local development
-----------------
The widget is served at /widgets/kelley-booking-widget.js by the FastAPI
dev server, so the same script tag works locally if you point the host
page at http://localhost:8000 instead of kelleyautoplex.com.

Production
----------
In production, Nginx serves /widgets/* directly from disk; FastAPI is
not in the request path for the widget asset itself.
